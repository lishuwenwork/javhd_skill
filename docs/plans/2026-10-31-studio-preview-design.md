# 工作室视频预览解析修复

用户提供的工作室详情页通过匿名只读 HTTP 成功复现：公开 ID 为 1789639070，页面播放器 videoId/content-id 为 130782，当前播放器的预告响应 sources 却使用媒体目录 86708。前两个编号对应的五秒预览均为 404，接口给出的目录对应短预览为 206 且有 MP4 文件头。页面没有当前视频的内联预览字段，推荐卡片也没有当前视频。

- 保留已有页面/接口显式预览及普通 ID 短预览优先级；工作室跳过公开 ID 猜测，直接查询当前预告。
- 工作室或普通短预览不存在时，从已验证的当前播放器 endpoint 保留内部 ID 与其他参数，仅设 is_trailer=1，读取当前视频的预告响应。
- 只处理该响应中明确位于 trailers 目录的 MP4；优先验证同目录五秒预览，不可用时才验证接口实际提供的预告 MP4。不得将完整源、推荐卡片或播放器内部 ID 猜成预览。
- 所有候选限量读取 64 字节，核对 HTTP 状态及 MP4 文件头；失败不影响完整源解析，不自动下载完整视频或上传。
- 上传 resolver 与诊断 probe 共用实现；补充工作室三种 ID 不同、普通页面兼容、错误响应、无预告及禁止完整源冒充预览的离线测试。同步文档及新 ZIP，并用用户原页面只读验证。

修复后的原页面只读验证已确认 MP4 预览来自媒体目录 86708，HTTP 206，Range 为 bytes=0-63；封面及完整源 URL 也可解析。中文标题在详情页及播放响应中均缺失，四项诊断总 success 仍为 false；该限制和预览修复分别报告，不改写标题规则，不执行下载或发布。
